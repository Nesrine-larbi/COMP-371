## 👩‍💻 Project Description

This application lets users explore a 3D solar system scene using keyboard and mouse controls. The scene includes:

- Interactive camera (first-person style)
- Planets orbiting a sun
- Moons orbiting planets (hierarchical animation)
- Textured 3D objects (planets, ground, sky)
- Basic lighting (static or dynamic depending on version)

Built with:
- OpenGL
- GLFW
- GLAD / GLEW
- GLM
- stb_image.h
- OBJ loader from tutorial 5

---

## 🕹️ Controls

| Key / Mouse | Action                        |
|------------|-------------------------------|
| W / A / S / D | Move forward, left, back, right |
| Space       | Move up                      |
| Left Shift  | Move down                    |
| Mouse       | Look around (rotate camera)  |
| ESC         | Exit the program             |
